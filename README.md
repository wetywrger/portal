# 🏢 Корпоративный справочник
Легковесный веб-портал для просмотра сотрудников и подразделений компании.  
Включает публичный каталог, админ-панель с авторизацией, поиск, загрузку фотографий сотрудников и управление данными. Разворачивается в Docker за 5 минут без ручной настройки окружения.

## ✨ Возможности
- 📇 Карточки сотрудников с фото, контактами, должностью и отделом
- 🔍 Регистронезависимый поиск и сортировка по алфавиту
- 🏢 Фильтрация по подразделениям
- 🔐 Админ-панель: CRUD сотрудников, загрузка фото, управление подразделениями
- 🐳 Полная контейнеризация: `FastAPI` + `React` + `Nginx` + `SQLite`

## 🚀 Быстрый старт

### Требования
- `Docker` и `Docker Compose` (v2+)
- `git`
- Свободный порт `777` на сервере

### Установка
```bash
# 1. Клонируйте репозиторий
git clone https://github.com/wetywrger/portal.git
cd corporate-portal

# 2. Соберите и запустите контейнеры
docker compose up -d --build
